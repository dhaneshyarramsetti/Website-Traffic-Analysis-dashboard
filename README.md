# 🌐 Website Traffic Analysis Dashboard

![Dashboard Preview](Screenshot%202026-08-02%20124702.png)

## 📌 Project Overview

The **Website Traffic Analysis Dashboard** is an interactive Power BI dashboard designed to analyze website traffic and user behavior. It helps businesses monitor website performance by visualizing key metrics such as visitors, sessions, page views, bounce rate, traffic sources, and user engagement.

---

## 🚀 Features

- 📊 Interactive Power BI Dashboard
- 👥 Visitor and Session Analysis
- 📈 Website Traffic Trends
- 🌍 Traffic Source Analysis
- 📄 Page Views and User Engagement
- 📉 Bounce Rate Monitoring
- 📱 Responsive and Interactive Visualizations

---

## 📊 Key Metrics

- Total Visitors
- Total Sessions
- Total Page Views
- Bounce Rate
- Average Session Duration
- Traffic Sources
- Device Distribution

---

## ▶️ How to Use

1. Download or clone this repository.
2. Open `dashboard3.pbix` in Microsoft Power BI Desktop.
3. Explore the interactive dashboard.
4. Update the `WTA.xlsx` dataset if needed and refresh the report.
